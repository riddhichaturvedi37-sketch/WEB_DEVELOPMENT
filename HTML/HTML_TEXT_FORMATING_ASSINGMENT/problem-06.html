JavaScript

JavaScript is a programming language mainly used to make web pages interactive and dynamic. It can be used for creating buttons, animations, forms, and interactive websites.

Important Concept: JavaScript can run directly in a web browser. 


let name = "Riddhima";
console.log("Hello " + name);

Java

Java is a popular programming language used for software development, web applications, Android applications, and enterprise applications.

Important Concept: Java is an object-oriented programming language. 


public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Python

Python is a simple and powerful programming language used for web development, data science, artificial intelligence, automation, and machine learning.

Important Concept: Python has simple and easy-to-read syntax. 


name = "Riddhima"
print("Hello", name)
